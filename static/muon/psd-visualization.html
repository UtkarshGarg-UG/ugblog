Quadratic Forms: Bowl vs Saddle

PSD matrices create bowls (always ≥ 0). Non-PSD matrices create saddles (can go negative).

PSD Matrix (All λ ≥ 0)

A = [2, 1; 1, 2]
Eigenvalues: λ₁ = 3, λ₂ = 1
xᵀAx = 18 ≥ 0 ✓

Non-PSD Matrix (Some λ < 0)

B = [1, 0; 0, -1]
Eigenvalues: λ₁ = 1, λ₂ = -1
xᵀBx = -1 < 0 ✗

What you're seeing: The height of the surface at point (x₁, x₂) shows the value of xᵀAx.

• PSD (left): The surface is a bowl — it never goes below zero. All eigenvalues are positive, so the quadratic form is always ≥ 0.

• Non-PSD (right): The surface is a saddle — it goes negative in one direction (along the eigenvector with negative eigenvalue). Move x₂ and watch it dip below zero!
