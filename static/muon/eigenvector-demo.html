The blue vector is your input x. The purple vector is Ax (the output after applying the matrix).

• Not an eigenvector: The output points in a DIFFERENT direction than the input — the matrix both stretches AND rotates.

• Eigenvector: The output points in the SAME direction (or exactly opposite) — the matrix ONLY stretches, by factor λ.

This diagonal matrix stretches 2× along x-axis and 3× along y-axis. So the eigenvectors are the axes themselves!
